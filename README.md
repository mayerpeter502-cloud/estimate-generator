\# Генератор смет



Универсальный веб-инструмент для создания профессиональных смет и коммерческих предложений в PDF. Подходит для автосервисов, строительных бригад, ателье, ремонтных мастерских и любых услуг.



\## Возможности



\- \*\*Импорт прайс-листа из Excel\*\* (.xlsx) — массовая загрузка услуг одной операцией

\- \*\*Выбор услуг\*\* с автоматическим подсчётом итогов

\- \*\*Генерация PDF\*\* с поддержкой кириллицы, датой, номером документа и местами для подписей

\- \*\*Корректная обработка\*\* длинных названий (автоматический перенос строк) и больших сумм (до 1+ млн ₽)

\- \*\*Универсальное поле "Объект работ"\*\* — подходит для авто, одежды, стройки, IT, услуг

\- \*\*История смет\*\* с возможностью просмотра и повторного скачивания PDF

\- \*\*Адаптивный интерфейс\*\* — работает на десктопе и мобильных устройствах

\## Установка и запуск



\### Вариант 1: Docker (рекомендуется)



1\. Клонируйте репозиторий или распакуйте архив с проектом

2\. Перейдите в папку проекта:



```bash

cd estimate-generator

```



3\. Запустите проект одной командой:



```bash

docker-compose up -d

```



4\. Откройте браузер и перейдите по адресу:

&#x20;  - Frontend: http://localhost

&#x20;  - Backend API: http://localhost:8000



Для остановки проекта:



```bash

docker-compose down

```



\### Вариант 2: Локальный запуск (для разработки)



\*\*Backend:\*\*



```bash

cd backend

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

uvicorn main:app --reload --port 8000

```



\*\*Frontend:\*\*



```bash

cd frontend

npm install

npm run dev

```



Откройте http://localhost:5173

\## Использование



1\. \*\*Создание бизнеса\*\*: При первом запуске автоматически создаётся демо-бизнес "Демо Автосервис"

2\. \*\*Импорт прайса\*\*: Загрузите Excel-файл с колонками "Наименование", "Цена", "Единица"

3\. \*\*Создание сметы\*\*:

&#x20;  - Введите имя клиента и телефон

&#x20;  - Укажите объект работ (например: "Toyota Camry, А123БВ77" или "Куртка Аляска, р.52")

&#x20;  - Выберите нужные услуги

&#x20;  - Нажмите "Создать смету"

4\. \*\*Скачивание PDF\*\*: Перейдите в "История смет" и нажмите "📄 Скачать PDF"



\## Формат Excel для импорта



Файл должен содержать три колонки (в любом порядке, но с заголовками):



| Наименование | Цена | Единица |

|--------------|------|---------|

| Замена масла | 1500 | услуга |

| Диагностика | 800 | услуга |
